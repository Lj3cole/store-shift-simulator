# 輪到你值班｜3D 超商打工模擬器

以超商打工者為主角的電腦網頁小遊戲。一班五分鐘，隨機安排白班或晚班，挑戰收銀、微波、補貨、清潔、突發事件與交班，看看能撐過幾天。

## 開啟方式

下載 index.html 後直接用瀏覽器開啟，或透過本專案的 GitHub Pages 網站遊玩。不需要 API 金鑰或安裝套件。

## 操作

- WASD：移動；滑鼠：轉動視角；E：互動；Esc：離開操作或暫停。
- 收銀：拖動商品穿過掃描區，使用錢櫃找零或輸入刷卡金額。
- 微波：結帳後餐點直接拿在手上，點爐門開關、點餐盒放入與取出，再按實體數字鍵加熱。
- 補貨：司機到貨並驗收後，把貨箱商品放到同名稱貨架格位。
- 無人領取的餐點可按「丟棄手上餐點」清空雙手。

## 專案檔案

- index.html：完整遊戲，包含 CSS、JavaScript、Three.js 與程序生成模型。
- docs/specification.md：遊戲規格。
- docs/test-report.md：檢查紀錄與測試限制。
- docs/submission.md：補交作業文字範本，需填個人資料、週次、網站網址與自己的截圖。
