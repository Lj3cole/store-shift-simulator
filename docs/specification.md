# 輪到你值班｜定案規格書 v0.2

## 已確認的核心
- 第三人稱簡化3D，正常比例人物、藍綠白店面，自製幾何與商品。
- 打工者身分；一局一天的一個班，隨機白/晚班。WASD、移動滑鼠轉視角、E互動，收銀與微波切第一人稱。無員工招募。
- 12種飲料、零食、鮮食。客人拿貨減少庫存，逐件掃描、現金選錢幣找零、刷卡輸入金額。
- 每位客人最多一份需加熱餐，付款後另到取餐區。兩台微波爐各一份，獨立計時、聲音及編號提示，錯誤交餐被阻止。
- 到貨核對與短少回報、倉庫搬箱、對應貨架上架、不得超過容量。補貨期間能請同事支援收銀，微波仍由玩家負責，交回櫃台後同事離開。
- 垃圾要搬到店外指定區；清潔打翻處需先拿拖把。六種事件為插隊、催促、價格爭議、打翻、延遲到貨、短少。
- 阿哲（仔細直接）、怡君（親切耐心）、阿志（輕鬆幽默）輪班。下班出現下一班同事，根據真實待辦清單對話，未完整交代會被追問。
- 無血腥推擠、揮拳有確認及後果；一般錯誤可修正，警告明示原因；三次正式警告或揮拳提前解僱。
- 每班結算後本機保存天數、評價、警告歷史；被解僱重新開始，不跨裝置同步。

## 測試初值
- 一班600秒；白班07:00–15:00、晚班15:00–23:00，時間壓縮。
- 到貨200秒，延遲時260秒。垃圾330秒開放。前兩天2個事件，後續3個，時點85/275/445秒；物流事件至多一個，排在到貨前。
- 每品項貨架5、倉庫4件；貨架容量8、搬箱最多4。驗收通常每項4件，短少案例第一項2件。
- 微波8或15秒，為遊戲設定，不是食品指示。
- 客人約每22–27秒一位（後續天數18–23秒），場內最多7位。等候145秒離店並提醒，等餐160秒提醒；同一事件不按幀重複計罰。
- 一般失誤每三次升為正式警告；嚴重客訴/推擠直接一警告。單筆收銀同錯重試不重複扣分。

## 第一版表現限制
幾何人物和預寫對話，沒有生成式AI、真人動作、真實金流、官方POS或官方營運資料。支援走位、碰撞及NPC路徑為簡化遊戲實作，後續依玩家試玩調整。

## v0.2：方塊人物與第一人稱工作
- 人物、貨架商品統一採方塊低多邊形造型，商品保留可辨認的瓶身、紙盒、零食袋與餐盒。
- 第三人稱移動滑鼠即可旋轉；點畫面啟用連續滑鼠視角，Esc 釋放。
- 收銀切換第一人稱。拖商品穿越紅色掃描區才登錄；單點不掃描，已掃商品不重複計價。
- 現金商品掃完後顯示打開的錢櫃，點實體面額選取找零；刷卡仍需核對金額。
- 微波切換第一人稱。查看食品的遊戲秒數，開門放入、關門，點 0–9 數字鍵與啟動鍵；也支援實體鍵盤。
- 微波秒數為縮時遊戲設定，並非真實食品加熱指示。兩台獨立計時，不搶走另一台的操作畫面。

## v0.3：五分鐘生存班與實體工作流程（本節取代舊版時程與補貨方式）
- 每班300秒，HUD直接顯示剩餘時間。白晚班仍隨機；完整交接後繼續下一天，結算顯示撐過的天數，三次正式警告或攻擊仍會解僱。
- 送貨100秒（延遲130秒）、垃圾165秒、事件45/140/225秒。初始貨架有貨，倉庫沒有可補商品；只有司機到店、核對驗收後才開放補貨。
- 司機有方塊人物、名稱與到貨提醒；不需要等客人說缺貨。另有真正出現的問路NPC，答對分類後會向商品貨架行走，不能重複刷指路分數。
- 玩家結帳後待加熱餐點自動拿在手上，第三人稱能看到餐盒和客人編號；同事代收銀的餐點保留備餐台取餐流程。
- 微波第一人稱顯示雙手和餐盒。開門放入時餐盒由手移到爐內，關門後輸入秒數啟動；完成後開門，餐盒由爐內移到手上，必須再關門才能離開。兩台爐門、待啟動餐點和計時互相獨立，離開後再進入不會丟失餐點。
- 第一人稱補貨分飲料、零食、鮮食三架，每架四個固定品項。下方對應貨箱，上方對應區格，同名稱、顏色和商品造型。點貨箱選一件，再點對應貨架，播放上架動畫。錯架不扣庫存，滿8件不可再放，動畫期間阻止重複上架。
- 仍為單一index.html，不使用真實金流或即時AI；微波秒數為遊戲縮時。


## v0.4 互動修正（2026-11-18）
- 前兩天客流調為每 32～37 秒一位，之後每 28～33 秒一位，店內上限 5 人。
- 結帳後待微波餐點直接拿在手上，不必再向客人領取；取餐客人在微波區前方等待。
- 新增「丟棄手上餐點」，只清除該份餐點及對應訂單，不影響其他人的餐點；無人領取時仍能清空雙手。
- 微波爐改為點實體爐門／把手開關、點手上餐盒放入、點爐內餐盒取出；保留實體數字鍵與餐盒移動動畫。
- 貨架增加分類、商品與格位標示；補貨區增加開箱商品與推車，清潔區增加拖把、水桶及掃把，垃圾區增加垃圾桶、垃圾袋及指示牌。
