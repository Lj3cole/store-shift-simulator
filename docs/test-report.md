# v0.1 測試紀錄
2026-11-17

## 狀態測試：16組通過
商品數與同事設定、隨機班別、找零計算、庫存非負/一單一熱食、NPC路徑避障、現金修正與防重複、刷卡金額、錯架阻止與庫存轉移、支援到達與歸還、雙微波/暫停/交餐、短少驗收防重複、拖把清潔/垃圾搬運、班末交接/保存、三警告解僱、揮拳解僱、50次事件計畫合法性。

## 修正
- 同事支援後無法交還：修為到櫃台可開啟接班對話。
- 同一訂單多份熱食只處理一份：第一版約束每個購物籃最多一份鮮食。
- 物流事件可能出現在驗收之後：每班最多一個，且排在到貨前，不倒扣已驗收庫存。
- 顧客離隊時收銀單仍可付款：清除過期單，付款前確認客人仍在排隊。
- 測試環境無WebGL：加入同一3D場景與相機的Canvas軟體相容渲染，不另做靜態示意畫面。

## 瀏覽器實測
主畫面、領班表、打卡、時間/任務HUD、E開啟收銀、暫停及恢復可以運作。WebGL硬體渲染在此瀏覽器不可用，目前視覺檢查使用Canvas相容路徑。

## 待使用者試玩
十分钟實際鍵鼠走動的節奏、整班事件壓力、不同電腦WebGL畫質與效能。自動狀態測試使用模擬DOM，不能聲稱所有操作已在真實瀏覽器中完整跑過。
